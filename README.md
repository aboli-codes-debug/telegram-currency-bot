# 🤖 Telegram Currency & Date Bot

یک ربات تلگرامی کاربردی که قیمت لحظه‌ای دلار/تومان را استخراج کرده و در کانال تلگرامی ارسال می‌کند. همچنین این ربات قابلیت ارسال پیام‌های روزانه همراه با تاریخ دقیق شمسی را دارد.

## ✨ ویژگی‌ها (Features)
*   **آپدیت لحظه‌ای ارز:** دریافت قیمت زنده دلار/تومان و پست کردن خودکار آن در کانال.
*   **تقویم شمسی (Jalali Date):** ارسال پیام‌های خوش‌آمدگویی و اطلاع‌رسانی روزانه با تاریخ شمسی.
*   **امنیت بالا:** استفاده از متغیرهای محیطی (`.env`) برای مخفی نگه داشتن توکن ربات (API Token).

## 🛠️ تکنولوژی‌ها
*   `Python`
*   کتابخانه‌های API تلگرام
*   کتابخانه‌های تبدیل تاریخ شمسی در پایتون
